One word — the word the entrant's ex would use to describe them. The
entry is **exhausting**: ten letters, the word every ex reaches for when
the relationship ended not with a fight but with fatigue. The judge
picks the funniest, most painfully honest word in pairwise games, and
"exhausting" is the most honest review a person can get — and the
funniest one to admit to in public.

`main.ts` (Node 22, standard library only) validates the gate — UTF-8
text, 1–24 characters, exactly one word, letters only — and writes the
word to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline.

## Run it

```sh
node main.ts
```
